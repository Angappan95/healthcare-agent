# Healthcare Agent

A healthcare research agent powered by LangGraph that searches PubMed articles and provides research-based answers to medical queries using AI.

## Features

- Natural Language Processing for keyword extraction
- PubMed API integration for medical literature search
- LLM-powered response generation
- LangGraph workflow orchestration
